# davidcglass.me

Static personal homepage for David C. Glass.

- `index.html` — the page (HTML + CSS, no build step)
- `hero.jpg` — background photo
- `og-image.jpg` — 1200×630 social share image

## Deploy

cPanel → Git Version Control → davidcglass.me → Pull or Deploy:
1. **Update from Remote**
2. **Deploy HEAD Commit**

`.cpanel.yml` copies the files into `/home/davidcglass/public_html/`.
